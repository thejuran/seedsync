# Roadmap: v3.0 Terminal UI Overhaul

**Goal:** Transform SeedSync's UI from generic Bootstrap/Verdana to a distinctive Terminal/Hacker aesthetic — dark-only, Fira Code + IBM Plex Sans fonts, matrix-green accents, ASCII progress bars, collapsible sidebar, CRT scan-line overlay.

**Design Spec:** `~/.claude/plans/sparkling-inventing-llama.md`

## Phases

### Phase 33: Foundation

**Goal:** Replace the entire color system, typography, and CSS variable foundation with the Terminal/Hacker palette.

**Requirements:** VIS-01, VIS-02, VIS-03, VIS-04, VIS-05

**Key Files:**
- `src/angular/src/index.html` — Add Google Fonts (Fira Code + IBM Plex Sans), hardcode `data-bs-theme="dark"`, remove FOUC theme script
- `src/angular/src/app/common/_bootstrap-variables.scss` — Replace palette (primary=#3fb950, danger=#f85149, warning=#f0883e), update fonts
- `src/angular/src/app/common/_common.scss` — Update layout variables (sidebar widths)
- `src/angular/src/app/common/_bootstrap-overrides.scss` — Remove light-mode overrides, dark-first dropdowns/forms, custom scrollbars
- `src/angular/src/styles.scss` — Replace all CSS custom properties with dark palette, remove light theme block, add CRT overlay, scrollbars, utility classes, keyframe animations

**Acceptance Criteria:**
- Fira Code renders for monospace data, IBM Plex Sans for UI text
- Background colors use #0d1117/#161b22/#1c2128 hierarchy
- Green accent palette (#00ff41, #3fb950, #238636) applied to primary actions
- CRT scan-line overlay visible at low opacity
- Custom dark scrollbars in webkit and Firefox
- App builds and renders without errors

### Phase 34: Shell

**Goal:** Restructure the app shell with collapsible icon-rail sidebar, minimal header, and terminal-style navigation.

**Requirements:** NAV-01, NAV-02, NAV-03, NAV-04

**Dependencies:** Phase 33 (Foundation must be in place)

**Key Files:**
- `src/angular/src/app/pages/main/app.component.html` — Restructure sidebar wrapper for hover expand
- `src/angular/src/app/pages/main/app.component.scss` — Sidebar 56px→200px on hover, content margin adjustment
- `src/angular/src/app/pages/main/sidebar.component.html` — Add `>` prompt indicator, version display, icon+text layout
- `src/angular/src/app/pages/main/sidebar.component.scss` — Dark bg, green active indicator, hover glow, icon-rail sizing
- `src/angular/src/app/pages/main/header.component.html` — Restyle notification alerts
- `src/angular/src/app/pages/main/header.component.scss` — Dark alert styles with terminal colors

**Acceptance Criteria:**
- Sidebar shows as 56px icon rail, expands to 200px on hover (CSS-only)
- Active route shows `>` prompt prefix
- App version displayed at sidebar bottom
- Mobile hamburger menu works as before
- No layout shift or overflow issues

### Phase 35: Dashboard

**Goal:** Redesign the file list with ASCII progress bars, status dot indicators, colored left borders, and terminal-style action bars.

**Requirements:** DASH-01, DASH-02, DASH-03, DASH-04, DASH-05, DASH-06

**Dependencies:** Phase 33 (Foundation), Phase 34 (Shell layout)

**Key Files:**
- `src/angular/src/app/pages/files/file-options.component.html` + `.scss` — Terminal `>` search prefix, dark inputs
- `src/angular/src/app/pages/files/file-list.component.html` + `.scss` — Dark header row, subtle alternating rows
- `src/angular/src/app/pages/files/file.component.html` + `.scss` — Status dots, ASCII progress bars, left border colors, glow effects
- `src/angular/src/app/pages/files/file-actions-bar.component.html` + `.scss` — Ghost buttons with glow
- `src/angular/src/app/pages/files/bulk-actions-bar.component.html` + `.scss` — Dark bg, green accents
- `src/angular/src/app/pages/files/selection-banner.component.html` + `.scss` — Dark bg, green border indicator

**Acceptance Criteria:**
- Search shows `>` prefix prompt
- File rows have colored left border by status (green/teal/amber/red)
- Progress bars render as ASCII blocks `[████░░░░] 67%`
- Downloading rows pulse with green glow
- Status shows colored dot + text (no SVG icons)
- Action buttons are ghost-style with glow on hover
- File selection, bulk actions still functional

**Requirements:** PAGE-01, PAGE-02, PAGE-03, PAGE-04

**Acceptance Criteria:**
- Settings sections use terminal-style `--- Name ---` headers
- AutoQueue patterns display in monospace with green add / red remove buttons

- About page has ASCII-art inspired layout with monospace version

### Phase 37: Theme Cleanup

**Goal:** Remove the now-unused light/dark/auto theme system and simplify to dark-only.

**Requirements:** CLEAN-01, CLEAN-02

**Dependencies:** Phases 33-36 (All visual work must be complete first)

**Key Files:**
- `src/angular/src/app/services/theme/theme.service.ts` — Simplify to always return dark (remove OS detection, localStorage toggle, storage event sync)
- `src/angular/src/app/services/theme/theme.types.ts` — Simplify theme types
- `src/angular/src/app/pages/settings/settings-page.component.ts` — Remove theme toggle logic and imports

**Acceptance Criteria:**
- Theme toggle removed from Settings page
- ThemeService simplified (no light/auto modes, no OS detection)
- No references to light theme in codebase
- App always renders in dark Terminal/Hacker theme
- All unit tests pass (update/remove theme-related tests as needed)
