**4. Add import detection logic** -- Find where the component subscribes to file updates. Look for the subscription to `_viewFileService.filteredFiles` or `_viewFileService.files`. The component sets `this.files = this._viewFileService.filteredFiles;` in the constructor or initialization.

Actually, looking at file-list.component.ts more carefully, `this.files` is an Observable that's assigned to `this._viewFileService.filteredFiles`. We need to subscribe to the UNFILTERED files to detect all import transitions (even filtered-out files should trigger toasts).

Add a new subscription in the constructor (or in an ngOnInit if one exists). The component uses DestroyRef and takeUntilDestroyed. Add AFTER the existing subscriptions in the constructor:

```typescript
        // Subscribe to file updates to detect import status transitions
        this._viewFileService.files
            .pipe(takeUntilDestroyed(this.destroyRef))
            .subscribe(files => {
                if (this._firstEmission) {
                    // First emission is initial load - record statuses without toasting
                    this._firstEmission = false;
                    files.forEach(file => {
                        if (file.importStatus) {
                            this._prevImportStatuses.set(file.name, file.importStatus);
                        }
                    });
                    return;
                }

                // Check for new imports
                files.forEach(file => {
                    const prevStatus = this._prevImportStatuses.get(file.name);
                    if (file.importStatus === ViewFile.ImportStatus.IMPORTED &&
                        prevStatus !== ViewFile.ImportStatus.IMPORTED) {
                        this._toastService.success("Sonarr imported: " + file.name);
                    }
                    // Update tracked status
                    if (file.importStatus) {
                        this._prevImportStatuses.set(file.name, file.importStatus);
                    }
                });

                // Clean up removed files
                const currentNames = new Set(files.map(f => f.name));
                for (const name of this._prevImportStatuses.keys()) {
                    if (!currentNames.has(name)) {
                        this._prevImportStatuses.delete(name);
                    }
                }
            });
```

Design decisions:
- Uses UNFILTERED files (`files` not `filteredFiles`) so import toasts fire even if the file is hidden by a filter.
- `_firstEmission` flag prevents toasting on page load for files already in IMPORTED state.
- Tracks previous import statuses in a Map keyed by file name.
- Only fires toast when transitioning FROM non-IMPORTED TO IMPORTED.
- Cleans up the map when files are removed from the model (prevents memory leak).
- Uses `takeUntilDestroyed(this.destroyRef)` which is the existing cleanup pattern in this component.
- Toast message format: "Sonarr imported: Show.Name.S01E05" -- concise, includes the file name for identification.

- Add debouncing or batching (keep it simple per research recommendation)
