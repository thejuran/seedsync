<objective>
Add realpath()-based path traversal guards to all file-destructive endpoints (delete_local, delete_remote, extract) and the bulk endpoint, ensuring paths that resolve outside local_path are rejected with 400 Bad Request.

Purpose: PATH-01/PATH-02 prevent directory traversal attacks via `../` sequences or symlinks in filenames. PATH-03 ensures the error response leaks no filesystem path information to attackers.

Output: `_check_path_safe` guard method on ControllerHandler, early-exit calls in 3 individual handlers + bulk endpoint, constructor wiring for local_path, passing tests for all traversal cases.
</objective>

    **GREEN phase — implement guard:**

    Step 1: Update ControllerHandler constructor to accept local_path:
    ```python
    import os
    from pathlib import Path

    class ControllerHandler(IHandler):
        def __init__(self, controller: Controller, local_path: str = ""):
            self.__controller = controller
            self.__local_path_real = Path(os.path.realpath(local_path)) if local_path else None
            self._bulk_request_times: List[float] = []
            self._bulk_rate_lock = Lock()
    ```

    Note: `local_path` defaults to empty string for backward compatibility with existing tests that only pass `controller`. When empty, `__local_path_real` is None and the guard is a no-op (allows all). This prevents breaking the existing 40+ tests.

    Step 2: Add _check_path_safe guard method:
    ```python
    # Path-destructive actions that require traversal guarding
    _GUARDED_ACTIONS = {
        Controller.Command.Action.DELETE_LOCAL,
        Controller.Command.Action.DELETE_REMOTE,
        Controller.Command.Action.EXTRACT,
    }

    def _check_path_safe(self, file_name: str):
        """
        Returns HTTPResponse(status=400) if file_name resolves outside local_path, else None.
        Uses realpath() to resolve both '..' sequences and symlinks.
        """
        if self.__local_path_real is None:
            return None
        candidate = Path(os.path.realpath(
            os.path.join(str(self.__local_path_real), file_name)
        ))
        if not candidate.is_relative_to(self.__local_path_real):
            logger.warning("Rejected path traversal attempt for: %s", repr(file_name))
            return HTTPResponse(body="Invalid file path", status=400)
        return None
    ```

    Step 3: Add early-exit guard calls in the three individual handlers.
    In each of __handle_action_delete_local, __handle_action_delete_remote, __handle_action_extract — add immediately after `file_name = unquote(file_name)`:
    ```python
    guard = self._check_path_safe(file_name)
    if guard:
        return guard
    ```
