<objective>
Change the restart endpoint from GET to POST to prevent CSRF attacks.

Purpose: GET-based state-changing endpoints are a CSRF vector — any page with `<img src="/server/command/restart">` can force a restart. POST requires a deliberate form submission or XHR call.
Output: Backend registers restart as POST-only; Angular calls POST; both test suites updated.
</objective>
